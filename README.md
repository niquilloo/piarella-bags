# Piarella Bags – Tienda web

Tienda en línea de **Industrias Marzzelli Perú Cueros E.I.R.L.** (Piarella Bags): carteras, mochilas, morrales, calzado, correas, billeteras y monederos.

- Un solo archivo: `index.html` (HTML + CSS + JavaScript, sin dependencias). Se abre con doble clic.
- Pedidos por WhatsApp; pago con Yape, Plin o transferencia.
- Logo en `logo/`.

## Antes de publicar
Editar el bloque `CFG` dentro de `index.html` con los datos reales (WhatsApp, Yape/Plin, cuenta bancaria). Hoy son datos de ejemplo.

## Limitaciones conocidas
- Productos y precios de ejemplo; imágenes son ilustraciones (faltan fotos reales).
- Pedidos y stock se guardan solo en el navegador del cliente (sin panel de administración).
- Textos legales en borrador, pendientes de revisión legal.

Cada commit es una versión de la tienda (ver `git log`).
